# Media coverage rollout — 2026-11-23

## Delivered

- Content dataset contains 72 draft articles across 12 stages.
- Six existing custom editorial covers preserved.
- 66 additional distinct, original **procedural SVG** article covers generated by `scripts/generate-media.mjs` from each article title, stage and illustration motif.
- Three pre-existing source-referenced infographics preserved.
- The assets are illustrations, not photos, medical diagrams or clinical evidence.
- Each generated cover is named `/media/auto-cover-<article-slug>.svg` and has unique alt text.
- All 72 cover URLs now exist in the content manifest. Generated SVG files are build outputs and gitignored.
- `generate:media` executes before content validation and before Next.js local dev and production builds.
- `check-content.mjs` asserts 72 unique covers, six custom covers, 66 generated covers, three infographic assets, accessible alt text and local file existence.
- Supabase `mebe.knowledge_articles.payload.media.cover` had 66 missing entries populated only when the cover was absent; no medical content, editorial status or review flags were changed.
- Independent database verification returned **72 total, 72 covers, 72 unique cover URLs**.
- GitHub Actions CI on commit `eb280a902dc185688f1455a12bcac1f03d3d4d6a` completed successfully.
- PR #1 remains draft, not merged.

## Important limitations

1. Render production/development deployments have not been visually checked against the newest media commit. A deployment must build from the current branch to serve the generated assets.
2. Build-time SVG covers are distinct illustrations, **not** 66 commissioned editorial photos. Upgrade priority pages with reviewed professional artwork when available.
3. The build generator cannot run at runtime for articles created solely in the CMS. A later version needs an upload-backed media service or object storage with signed editorial writes.
4. Existing CMS revisions and snapshots may predate the cover backfill. Runtime article payloads have been augmented without changing review state; future workflows must treat media updates as explicit audited revisions.
5. All 72 articles remain DRAFT and must not be publicised as medical advice.
6. Revisit `README.md` legacy descriptions: some older sections still say 24 drafts or no hosted database, while the later updates and verified database state supersede them.
