# Media import – DEV
Set on API server only: MEDIA_SUPABASE_URL, MEDIA_SUPABASE_SERVICE_KEY (legacy service_role), MEDIA_DEV_EDITOR_TOKEN, MEDIA_DEV_REVIEWER_TOKEN, MEDIA_DEV_ENABLED=true. Distinct random tokens; never commit secrets. Do not enable until all CI passes.
Run from project root: npm run generate:media; npm run media:import -w @mebe/api (dry run). Run db:migrate against Supabase only; no seed/reset. Then npm run media:import -w @mebe/api -- --apply. Source inventory includes generated and original WebP/SVG in web/public/media and review archive. Verify signed download SHA-256 for each unique object. Populate 72 cover + 72 inline active links only if no prior revision exists. Never publish article, replace a reviewed revision or delete source. Catalog preserves all legacy and review source paths. No public delivery, frontend cutover or clinical approval. Existing archive SVG trusted only after strict validation. On a partial failure rerun; it validates existing immutable objects. For production use a separate audited workflow.
